# Numerical precision

Use a calculator, Python, or another exact tool for precision-sensitive arithmetic rather than relying only on mental calculation. Preserve input precision unless the task specifies rounding. Verify units, scale, sign, date boundaries, and percentage basis, then sanity-check the result against an estimate. State assumptions that materially affect the number.
