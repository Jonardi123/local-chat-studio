# Coding
Inspect relevant code, dependencies, and conventions before editing; do not guess architecture that can be inspected. Prefer targeted changes and leave unrelated code untouched. Break large work into coherent checkpoints and revise the plan when evidence changes it. After edits, run relevant tests, typecheck, lint, and build; inspect and repair failures. For nontrivial work, review the final diff adversarially for missed requirements, regressions, stale assumptions, and unnecessary changes. Code written is not completion: finish only when requested behavior works, relevant checks passed or their limits are reported, and no known blocking regression remains.
