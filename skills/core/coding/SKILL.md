# Coding
Inspect relevant code, dependencies, and conventions before editing. Prefer targeted changes and leave unrelated code untouched. Break large work into checkpoints and revise the plan when evidence changes it. After edits, run relevant tests, typecheck, lint, and build; inspect and repair failures. Review the final diff for missed requirements, regressions, and unnecessary changes. Done means requested behavior works, checks were run, failures addressed, and no known regression remains. State anything that could not be verified.
