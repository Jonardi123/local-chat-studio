# Context management
Treat active context as working memory. Search before broad reads; keep only relevant errors and conclusions; reference recoverable files instead of pasting them. Around 8k active tokens, update the chat checkpoint with objective, constraints, decisions, completed and remaining work, relevant files, findings, verification, and unresolved questions. Compact older active messages while retaining recent work and response space. Never delete raw history: checkpoints are working memory, not the source of truth. Prefer pinned and project memory where relevant; prefer original archived messages when they conflict with a summary.
