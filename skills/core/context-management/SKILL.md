# Context management
Treat active context as working memory and files, Git, tools, and archived chat as external memory. Search before broad reads; summarize large output; retain decisive errors and conclusions; do not reread unchanged files without a reason. Around half the active budget, update a compact checkpoint after meaningful milestones with objective, constraints, decisions, completed work, changed files, failures, test status, and next step. Compact older active messages while preserving recent work and response space. Never delete raw history. Recover older instructions through archive search when needed, and prefer the original message over a conflicting summary.
