# Failure recovery
Inspect the failure, form a root-cause hypothesis, gather missing evidence, try a revised approach, and verify. If the same strategy fails twice, stop: summarize attempts and new evidence, revise the hypothesis, then choose a materially different approach. Stop repeating conclusions that add no evidence. After multiple sensible approaches fail, report what was tried, learned, why progress is blocked, and the exact input or action required.
